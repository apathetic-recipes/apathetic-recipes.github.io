What are some alternatives?

GitHub

If writing on GitHub, you can use convenient shortcodes for many emoji. See the Github Emoji Cheat Sheet to check which ones are supported. You can also paste UTF-8 emoji directly without using shortcodes.

See our ✂️ Astro Starlight Icons by Category Snippet for inspiration when using that framework for even more options including SVG icons.
